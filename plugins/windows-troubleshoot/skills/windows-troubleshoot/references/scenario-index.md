## SDP reports (`-SDP <name>`)

- `Cluster`: Windows Failover Cluster Diagnostic Report - comprehensive diagnostics for failover clustering, Storage Spaces Direct (S2D), and Hyper-V host issues.
- `Dom`: Domains/Active Directory Diagnostic Report - comprehensive AD domain and forest diagnostics.
- `Net`: Comprehensive Network Diagnostic Report - most frequently used SDP for network connectivity and configuration issues.
- `RFL`: Recommended Fix List (RFL) Report - scans system for missing Windows updates, cumulative updates, and known hotfixes that address specific issues.
- `Setup`: Windows Setup Diagnostic Report - comprehensive diagnostics for Windows installation, upgrade, and feature update issues.
- `SQLbase`: SQL Server Basic Diagnostic Report - foundational SQL Server configuration and health data.
- `SQLsetup`: SQL Server Setup Diagnostic Report - troubleshoots SQL Server installation, upgrade, and patch failures.
- `SUVP`: SUVP (Setup/Update Validation Platform) Report - validates Windows update and servicing stack integrity.
- `VSS`: Volume Shadow Copy Service (VSS) and backup report.
