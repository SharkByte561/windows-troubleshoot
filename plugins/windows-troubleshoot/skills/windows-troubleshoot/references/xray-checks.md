# xray known-issue checks (TSS 2026.11.02.0)

xray runs automatically with every TSS collection (unless `-noXray`) and writes `xray_ISSUES-FOUND_*.txt` and `xray_report_*.xml` into the data folder. It can also be run on its own: `.\xray\xray.ps1 -Component <component> -DataPath <folder> -AcceptEula`.
"Offline" = the check can work from collected data files (`-Offline`); the others need to run on the affected machine.
